\section{Distinct Primes Factors --- Problem 47}
\label{prob:47}
\noindent\textbf{Source:} \url{https://github.com/KO0I/projectEuler/blob/reorganize/solutions-by-language/solutions/c/distinct_primes_factors_47.c}

\noindent\textbf{Assessment:} Search implemented with external factor counter.

\subsection*{Mathematical goal}
Find the first four consecutive integers each having exactly four distinct prime divisors. For example, repetitions of the same prime count once.

\subsection*{How the C code works}
The main loop tests starts from \verb|i=4| upward. For each candidate start, it checks whether \verb|distinctpfactors(i)| through \verb|distinctpfactors(i+3)| all equal \verb|score=4|. If all four tests pass, the program prints the sequence and exits the loop. It asserts that 60 has three distinct prime factors as a basic check.

\subsection*{Correctness and limitations}
The function \verb|distinctpfactors| lives in \verb|support/c/functions/distinctpfactors.c| and is not declared in this source. Linking and a prototype are required; the helper's fixed-size factor array and counting logic also merit tests. The search limit of twenty million is arbitrary. The expected first integer is \texttt{...4043}, but the exact code and helper should be tested before certifying the result.
