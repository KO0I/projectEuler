\begin{abstract}
This document covers Project Euler problems 1 through 255. The original
explanations and assessments describe historical C attempts, including
unfinished programs and defects; their source links point to the preserved
reorganization branch. They must not be mistaken for assessments of the
subsequently corrected implementations.

{\color{red}\textbf{Reading the corrections:} Red, explicitly labelled
sections explain the repaired or completed C implementation. The main C
files now own their algorithms and call reusable mathematical helpers in
\texttt{support/c/euler\_common.c}. Historical programs remain under
\texttt{solutions/c/variants/historical/}. Problems 13 and 17 have new C
implementations as well as their preserved earlier analyses.}

Current answer coverage contains 255 C programs, 255 Rust programs, 120 Gforth
programs, and 191 Factor programs. Passing the fixed reference inputs is
evidence of correctness for those inputs, not a proof of a general-purpose
algorithm. The 120-entry Gforth run recorded in
\texttt{docs/VALIDATION\_FORTH\_1\_120.md} passes 115 entries with a
60-second limit per solver. The remaining five are timeouts; the run contains
no wrong answers or runtime errors.
\end{abstract}
