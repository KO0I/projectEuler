\begin{abstract}
This document explains the actual operations performed by the C source
files in the KO0I/projectEuler repository, ordered by Project Euler problem
number. Descriptions distinguish correct programs from unfinished attempts
and defects. Numerical reference answers, where shown, are not presented as
verified outputs unless the implementation supports them.
\end{abstract}
