\begin{abstract}
This document covers the 37 Project Euler problems represented in the
KO0I/projectEuler repository, in ascending problem order. The original
explanations and assessments describe historical C attempts, including
unfinished programs and defects; their source links point to the preserved
reorganization branch. They must not be mistaken for assessments of the
subsequently corrected implementations.

{\color{red}\textbf{Reading the corrections:} Red, explicitly labelled
sections explain the repaired or completed C implementation. The main C
files are now small entry points calling the corresponding algorithm in
\texttt{support/c/euler\_common.c}. Historical programs remain under
\texttt{solutions/c/variants/historical/}. Problems 13 and 17 have new C
implementations as well as their preserved earlier analyses.}

All 37 C answers, 37 Rust answers and 37 Forth answers passed the same-machine
validation baseline recorded in \texttt{docs/VALIDATION.md}. Each program was
run once in that profile. Passing the fixed reference inputs is evidence of
correctness for those inputs, not a proof of a general-purpose algorithm.
\end{abstract}
